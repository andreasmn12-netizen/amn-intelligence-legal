# amn-intelligence-legal

Legal pages (Terms of Service, Privacy Policy) for apps operated by **AMN
Intelligence** (Denmark). Served as a static Jekyll site via GitHub Pages.

Live site: https://andreasmn12-netizen.github.io/amn-intelligence-legal/

## Files

- `index.md` – landing page listing current apps and legal docs
- `terms.md` – Terms of Service (shared across all AMN Intelligence apps)
- `privacy.md` – Privacy Policy (GDPR-aligned)
- `_config.yml` – Jekyll config (cayman theme, pretty permalinks)

## Adding a new app

When AMN Intelligence launches a new app that needs legal URLs, add an entry
to the "Current apps" list in `index.md`. The Terms and Privacy are written
generically enough to cover any AMN Intelligence social-media-automation app
without edits.
